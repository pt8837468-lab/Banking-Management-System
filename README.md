# Bank Management System

A Python-based Bank Management System built using Pandas and CSV files.

## Features
- Create and View Bank Accounts
- Deposit and Withdraw Money
- Fund Transfer
- Transaction History
- Loan Application and Management
- Customer Services
- Input Validation

## Technologies Used
- Python
- Pandas
- CSV File Handling

## How to Run
1. Install Python.
2. Install Pandas using:
   pip install pandas
3. Run the program:
   python rubicon.py
